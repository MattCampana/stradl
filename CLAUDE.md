# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

**Stradl** ("Musical chairs for your Claude sessions.") is a Go CLI plus macOS menu bar agent that keeps every Claude Code session on every one of a person's Macs, including the Claude desktop app's Code-tab sidebar (records and layout), with union semantics for sessions: every session any device creates ends up on all devices. Under the default `everything` scope it also syncs all of `~/.claude` and every project folder sessions work in, `.git` included, mirroring deletes into the other Macs' trash. Files are gzip-compressed and age-encrypted before upload to storage the user owns (Azure Blob primarily; R2, S3, GCS, S3-compatible and WebDAV also work). It's a fork of tawanorg/claude-sync (MIT); the Go module path and `cmd/claude-sync` directory keep upstream's names to ease merges, but the binary, config dir and all user-facing text are `stradl`.

## Common Commands

```bash
make build            # bin/stradl for this Mac (cgo on darwin, for the menu bar)
make test             # go test ./...
make check            # gofmt -l, go vet, go test -short
make lint             # golangci-lint (.golangci.yml) + shellcheck on install.sh and scripts/
make vulncheck        # govulncheck, as CI runs it
make release VERSION=0.1.0 RELEASE_REPO=owner/stradl   # 4 archives + checksums.txt in dist/

go test -v -run TestSync ./internal/sync/            # multi-device engine tests (in-memory CAS store)
go test ./internal/storage/azure/                    # needs Azurite on 127.0.0.1:10000 (azurite-blob --loose); skipped otherwise
scripts/test-install.sh dist                          # end-to-end installer test against a local HTTP server
scripts/test-azure-setup.sh                           # azure-setup.sh against a fake az CLI
```

Version and release repo are injected at build time: `-ldflags "-X main.version=<semver> -X main.releaseRepo=<owner>/stradl"`.

## Architecture

- **CLI** — `cmd/claude-sync/`. Cobra root in `main.go`; other files register commands via `extraCommands` from `init()`: `sync_cmd.go` (`sync`), `status_cmd.go` (`status`, `diff` — dry-run previews), `agent_cmd.go` (`agent run|install|uninstall|restart|pause|resume|status`), `azure_wizard.go`, `release.go` (`update`, `changelog` against `releaseRepo`). `push`/`pull` are aliases for the two-way sync. `tray_darwin.go` is the fyne.io/systray menu bar (darwin+cgo only; `tray_other.go` otherwise).
- **Sync engine** — `internal/sync/engine.go`. `Syncer.Sync` / `Syncer.Preview` run one reconcile pass over the sync roots (`syncRoots`): `~/.claude` (scope paths; `everything` walks it all minus `claudeDeniedDirs`, credentials and `config.BuildArtifacts`), the desktop session index (`config.DesktopSessionsDir()`, namespaced `_desktop/sessions/`, only `<acct>/<org>/local_*.json`), and project folders (`folders.go`: discovered from transcript/record cwds, `extra_folders`, remote `.stradl-folder.age` markers and `~/.stradl/folders.json`; namespaced `_folders/<home-rel>/`; a folder inside a repo syncs the repo root; every git repo is its own root, synced only when a session works in it (a transcript's first cwd, a record's cwd, `extra_folders` or a marker; later cwds and touched `file_path`s, subagents' included, count only inside one of those, read incrementally via `cwdEntry.Scanned`/`Tail`; `credentialDirs` never sync; `dropSkippedNested` keeps checkouts in build output out; a needed submodule brings its `superproject`): an outer folder skips repos inside it (`children` are other roots, `nested` repos no session needs, from the scan and from remote `<dir>/.git/` and `<dir>/.git` keys; `syncRoot.owns`), a repo other Macs sync stays its own where it isn't cloned yet (`canonicalFolderIn`), and `.git/modules/` data syncs only for a needed submodule (`modules`, from its `.git` file); a folder with a git lock, including one in the gitdir a `.git` file points to, is deferred for the pass, and so is every root inside a deferred one; `isRepoDir` needs `.git/HEAD` or a `gitdir:` file; a missing repo whose only state came from its outer folder starts `fresh`; `placeSubmodules` creates empty folders for unsynced submodules after a reindex; `folders.json` records each folder's skipped repos for `FolderStats`; registered submodules (`.gitmodules`) are nested unless needed or a plain folder of files; a linked worktree brings its main repo (`mainWorktree`) and `.claude/worktrees/` otherwise stays per Mac (`claudeWorktree`, not applied in `dropSkippedNested`, so a worktree a session works in is its own root); a root that is itself a symlink never syncs, and later/touched paths through a link inside a folder are skipped, but folders keep their spelling (no symlink re-rooting); git path helpers go through `gitDirSplit` (`gitpaths.go`), which treats `.git/modules/<name>` as a git dir of its own (`parseModules` splits names by git-dir structure; `syncRoot.moduleFor` matches known names), so a submodule's index stays per Mac and its refs get the fast-forward/`stradl/` rules; merge/rebase/bisect state (`gitOperationState`) stays per Mac). Per file: local hash vs state, remote ETag vs state (never timestamps), then upload (compare-and-swap via `storage.Conditional`), download (atomic rename or append-only), or `reconcileBoth` (JSONL line-union merge in `merge.go`, newest-`lastActivityAt` for desktop records, `.conflict` copy otherwise). Union paths (`unionPath`: `projects/`, `history.jsonl`, `_desktop/sessions/`) keep local deletes local (`FileState.LocalDeleted`) and restore vanished remote copies; every other path mirrors deletes with `DeleteIf`, and other Macs move the file to `~/.stradl/trash` (`trash.go`, 30 days). `guardMassDeletes` holds back deletes of more than half a root unless `--allow-mass-delete`. Non-mergeable conflicts go through `chooseSide` (`gitaware.go`): newest wins, except first contact in project folders (the copy already in storage is the reference and this Mac's differing copy is kept as `.from-<Mac>` or in `~/.stradl/conflicts`; `.git` files of a repo this Mac never synced follow the reference, also when the stored copy is an older Stradl's frozen upload of a nested repo: a frozen-copy exception was tried and removed, since every variant risked another Mac's live work; an `inherited` root, a nested repo resuming with state from its outer folder, puts conflict copies aside; a branch conflict waits until the other Mac's commit is here) and branch refs (fast-forward, else keep the loser as `stradl/<branch>-<sha7>`). Jobs run in batches: files and objects, then working-tree merges, then `.git` metadata, then sidebar records. Records whose Mac serves the session over Remote Control are held back (`holdRemoteControlled`). Files above 32 MB stream (`stream.go`, `storage.Streaming`). `live.go` defers remote changes to transcripts owned by a running Claude process (`~/.claude/sessions/<pid>.json`). `desktop.go` adds a git-remote hint on upload and remaps/creates the session folder on download. `run.go` wraps a pass in the device lock (`lock.go`, flock on `~/.stradl/sync.lock`), then syncs MCP servers and the sidebar layout (`desktopstate.go`: three-way merge of `epitaxyPrefs` groups/membership/pins in `claude_desktop_config.json`, applied only while the app isn't running, pending in `~/.stradl/sidebar-pending.json`), then writes the device heartbeat (`devices.go`). `probe.go` provides cheap local/remote fingerprints for the agent.
- **Agent** — `internal/agent/`. `Runner` loop (local poll 20s + debounce, remote probe 60s, full interval, wake detection, pause file, Sync Now), `status.json`, log rotation, launchd plist (`com.breakpointdata.stradl`), desktop-app restart helper, menu bar icons in `icon/` (generated from `assets/brand`).
- **Dashboard** — `internal/dashboard/`. Local web UI (127.0.0.1, random port, key → cookie, Host/Origin guards) served by the agent or `stradl dashboard`; `model.go` is the contract, `local.go` the provider, `web/` the embedded vanilla JS UI.
- **Mac app** — `apps/macos/` (SwiftPM, SwiftUI, macOS 13+), built into a universal ad-hoc-signed `Stradl.app` by `scripts/build-app.sh` (Command Line Tools only, no Xcode) and shipped as `Stradl.app.zip`; `install.sh` puts it in /Applications (~/Applications if not writable) and `stradl update` keeps it current (`cmd/claude-sync/app_update.go`). The app never touches storage: it reads the agent's dashboard API (`~/.stradl/dashboard.json`, `?t=` key, `Origin` header for POST) and runs `stradl config|folders|circle|claude restart|diagnostics|agent …` (`cmd/claude-sync/app_cmd.go`, JSON via `--json`). `STRADL_SNAPSHOT_DIR=dir` makes it save each pane as PNG and quit. "Circle" is the user-facing name for the set of Macs syncing into one container (heartbeats in `_metadata/devices/`).
- **Storage** — `internal/storage/`. `Storage` interface plus optional `Conditional` (`UploadIf`, `DownloadWithETag`, `DeleteIf`, sentinels `ErrPreconditionFailed`, `ErrNotFound`) and `Streaming` (`UploadStream`, `DownloadStream`). `azure/` implements all (SAS or account key; ETags normalized unquoted; SAS signatures redacted from errors). Adapters self-register via `init()`; anything calling `storage.New` must blank-import them.
- **Crypto** — `internal/crypto/`. age X25519; passphrase mode uses Argon2id with a **fixed salt** so every device derives the same key. Don't "fix" the salt.
- **Config** — `internal/config/`. `~/.stradl/config.yaml` (0600). `scope: everything` is the default for new installs, and v2.0's `sessions` is migrated to it unless `scope_explicit`; `desktop_sync` and `folder_sync` (nil = on), `extra_folders`, `folder_exclude`, `sync_build_artifacts`, `sync_interval_seconds`, `path_map`.
- **Paths** — `internal/sync/paths.go`. `${HOME}` (and `path_map` tokens) in remote keys and in file content; project dir names use Claude Code's encoding (non-alphanumerics → `-`).

## Distribution

- `.github/workflows/release.yml`: on `v*` tags, a macos-15 runner checks it got the go.mod `toolchain` Go, tests, runs govulncheck and `scripts/build-release.sh` (darwin arm64/amd64 with cgo and `MACOSX_DEPLOYMENT_TARGET=13.0`, linux arm64/amd64 without), and publishes `stradl_<os>_<arch>.tar.gz` + `checksums.txt` + `install.sh` + `azure-setup.sh` with `gh release create`.
- go.mod's `toolchain` line is the Go release binaries are built with (setup-go reads it); bump it for Go security releases.
- `install.sh` (curl one-liner from `.../releases/latest/download/install.sh`) installs to `~/.local/bin` with checksum verification and adds the PATH line (`~/.zprofile`; `~/.bash_profile` for a bash login shell; `~/.profile` on Linux). On a new machine with a TTY it runs `stradl init` and `stradl agent install`; on a Mac with the agent plist it reruns `stradl agent install` without needing a TTY, retrying while the old agent finishes a sync. `scripts/azure-setup.sh` provisions Azure from Cloud Shell, including a lifecycle rule that deletes previous blob versions after 30 days.
- `install.sh` on main keeps the `REPLACE_OWNER/stradl` placeholder: release.yml rewrites the copy it attaches to each release, which is the one the README links. Only README, docs and the `release.go` default get the real owner when publishing (release builds inject it via ldflags anyway).

## Gotchas

- **The desktop app reads its sidebar only at launch.** Newly synced `local_*.json` records appear after Claude restarts; the agent counts them (`pendingDesktopRestart`) and offers a restart.
- **Never rewrite a live transcript.** Keep the `live.go` deferral; a running Claude process holds the conversation in memory.
- **ETags, not clocks.** Don't reintroduce timestamp comparisons for change detection; compare normalized ETags (`normETag`).
- **Union semantics for sessions.** Transcripts, prompt history and sidebar records never get remote deletes; deletes there stay local by design. Everything else mirrors deletes, but only into the other Macs' trash, never a hard delete, and behind the mass-delete guard.
- **Git repos sync file by file.** Keep the batch order (objects before refs/index), the git-lock deferral and `chooseSide`'s git rules; never run git commands that write (`runGit` sets `GIT_OPTIONAL_LOCKS=0`), and never use `/usr/bin/git` without checking `xcode-select` (it pops an install dialog).
- **Conflict copies never sync.** `.conflict.` names are excluded from every root.
- **Long project paths.** Claude Code truncates encoded project dir names over ~200 characters with a hash suffix; the `${HOME}` prefix rewrite still applies, but such dirs won't match the hash Claude Code would compute for the other device's path. The desktop app finds transcripts by session ID, so sessions still open there.
- **macOS privacy prompts (TCC).** Reading ~/Desktop, ~/Documents, ~/Downloads or the media folders makes macOS ask, and the read blocks until answered. `tcc.go` does the first read in the background (`folderGate`); never read those folders on the sync path without the gate.
- **iCloud-only files.** With iCloud Desktop & Documents and "Optimize Mac Storage", files can be dataless placeholders (`SF_DATALESS`). Never read one on the sync path: downloading can take hours while iCloud (`bird`) is busy, and a blocked read froze whole passes in v2.2.1. `setupICloud` (main) turns on-read downloads OFF for the process (reads fail at once with EDEADLK) and ON only for the downloader's locked threads (`icloud_darwin.go`, `setiopolicy_np` thread scope). The engine checks `fileInICloud` before hashing/reading, requests the download (`RequestICloudDownload`), skips the file into `SyncReport.InICloud`, and the agent retries in 45 s. `agent.classify` reports EDEADLK as `icloud`, never `offline` (a `syscall.Errno` also satisfies `net.Error`).
- **Symlinks** are skipped under `~/.claude` but carried as links in project folders (`stradl-symlink v1` blobs).
- **path_map doesn't apply to `_folders/` keys.** Project folders land at the same home-relative path on every Mac.
- **Do not add destructive operations** to the default code path without an explicit flag or confirmation.
