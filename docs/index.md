# Stradl

**Musical chairs for your Claude sessions.**

[How It Works](./how-it-works) | [Azure Setup](./azure) | [Security](./security) | [GitHub](https://github.com/MattCampana/stradl)

---

Stradl keeps every Claude Code session on every one of your Macs, in the Claude desktop app's Code sidebar and in `claude --resume`, even when each Mac has a different username and keeps projects in different folders. Sessions are encrypted on your Mac before they reach storage you own.

- **[How It Works](./how-it-works):** the union sync engine, merging, the desktop sidebar, folder matching, the background agent.
- **[Azure Setup](./azure):** create the storage container and token in Azure Cloud Shell.
- **[Security](./security):** what is encrypted, what the token can reach, and how to revoke it.

Install and day-to-day use are covered in the [README](https://github.com/MattCampana/stradl#readme).
